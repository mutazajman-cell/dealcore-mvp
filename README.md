# DealCore — витрина ноутбуков

Одностраничный сайт-витрина: dealcore.ae

## Структура
- `index.html` — сайт (HTML + CSS + JS в одном файле)
- `catalog.json` — каталог товаров (источник для витрины)

## Как обновить каталог
1. Открыть [Google Таблицу DealCore — Каталог витрины](https://docs.google.com/spreadsheets/d/1Ktm6N2mnT9wxUyIC3x9HrsUHuTdZi6OHp7LjART6mNY/edit)
2. Изменить нужные строки (цены, фото, статус)
3. Перегенерировать `catalog.json` (скрипт sync-catalog) и запушить в репо
4. Сайт автоматически подтянет новый каталог

## Колонки таблицы
- **Статус** — `витрина` (показывать) или любое другое (скрыть)
- **ID** — уникальный идентификатор модели (M-0001, M-0002, ...)
- **Бренд**, **Модель**, **Категория**
- **Краткая строка витрины** — что показывается на карточке
- **Процессор**, **Память**, **SSD**, **Экран полностью** — для блока «Описание»
- **Главное фото** — URL на фото
- **Цена Экспресс 3 дня** / **Цена Стандарт 7 дней** / **Цена Минимальная цена 14 дней**

## Логика витрины
- На карточке показывается цена «Стандарт 7 дней» + мелким шрифтом «от X ₽ при 14 днях»
- Кнопка **Купить** → шит с тремя вариантами доставки
- Кнопка **Описание** → шит с характеристиками + теми же вариантами
- Любая кнопка доставки → WhatsApp на `+971502980483` с заполненным сообщением

## Деплой
Запушено в `main` → автоматически попадает на GitHub Pages → проксируется на `dealcore.ae`.
